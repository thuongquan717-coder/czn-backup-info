Privacy Policy

Effective date: November 26, 2026

Purpose

CZN Codex Backup is a personal backup utility intended for use by the project owner.

Google Drive Access

The application uses rclone and the Google Drive API to upload, verify, download and restore project backups. It requests limited access through the drive.file scope.

Data Storage and Security

Project backups are intended to be encrypted locally before being uploaded to the owner's Google Drive. Authentication credentials are stored locally.

Data Sharing

The application does not sell personal data, use Google Drive data for advertising, or share backup contents with unrelated third parties.

Data Control and Deletion

The owner can revoke application access through Google Account settings and delete stored backups directly from Google Drive.

Google API Compliance

The application's use of Google API data is subject to the Google API Services User Data Policy, including applicable Limited Use requirements.
